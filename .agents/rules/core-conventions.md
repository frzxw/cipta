# Core Conventions

| Media Download | yt-dlp | Latest |

## 2. Language Rules

- Always use **TypeScript** with `strict: true` in all `tsconfig.json` files.
- Never use `any`. Use `unknown` if the type is truly unknown, and narrow it.
- Never use `as` type assertions unless absolutely unavoidable — document the reason inline.
- Prefer `interface` for object shapes. Use `type` for unions, intersections, and mapped types.
- Use the `satisfies` keyword for type-safe object literals.
- All enums used in the database schema must match the Prisma enum definitions exactly.

## 3. Monorepo Package Layout

```
cipta/
├── apps/
│   ├── api/          # NestJS Orchestrator (REST + WebSocket)
│   ├── web/          # Next.js Dashboard ("Control Tower")
│   └── worker/       # Standalone Node.js BullMQ processor
├── packages/
│   ├── database/     # Prisma schema + generated client (@cipta/database)
│   ├── shared/       # Cross-app types, constants, utils (@cipta/shared)
│   ├── ui/           # ShadcnUI component library (@cipta/ui)
│   ├── eslint-config/
│   └── typescript-config/
└── docs/             # Single Source of Truth (SSoT) for all documentation
```

## 4. Ubiquitous Language

Always use these exact terms in code, comments, and conversations. Never create synonyms.

| Term | Meaning |
|------|---------|
| **Source** | A URL or uploaded file representing raw, unprocessed input media |
| **Transcript** | Timestamped text representation of audio, generated by Whisper API |
| **Viral Spike** | A segment identified by LLM as having high viral potential |
| **Chunk** | A discrete video segment cut from a Source based on Viral Spike timestamps |
| **Asset** | A finished, rendered video file ready for distribution |
| **Variation** | A unique fingerprint variant of an Asset produced by the Guardian |
| **Cluster** | A logical group of social media Accounts sharing a content strategy |
| **Render Profile** | A saved configuration of Factory settings (captions, framing, output) |
| **Distribution Rule** | A configuration mapping a Render Profile to a Cluster with scheduling constraints |
| **Ingestor** | Module for acquiring raw media and extracting intelligence |
| **Factory** | The video production engine using FFmpeg |
| **Guardian** | The anti-shadowban security layer ensuring unique outputs |
| **Fleet** | Distribution and account management module |
| **Worker** | Standalone Node.js background service processing BullMQ jobs |
| **Orchestrator** | The NestJS API server |
| **Control Tower** | The Next.js dashboard UI |

## 5. File Naming Conventions

| Context | Convention | Example |
|---------|-----------|---------|
| NestJS Module | `<name>.module.ts` | `ingestor.module.ts` |
| NestJS Controller | `<name>.controller.ts` | `ingestor.controller.ts` |
| NestJS Service | `<name>.service.ts` | `ingestor.service.ts` |
| NestJS DTO | `<action>-<name>.dto.ts` | `create-source.dto.ts` |
| NestJS Guard | `<name>.guard.ts` | `jwt-auth.guard.ts` |
| Worker Processor | `<name>.processor.ts` | `ingestor.processor.ts` |
| Worker Service | `<name>.service.ts` | `downloader.service.ts` |
| Test File (Unit) | `<name>.spec.ts` | `ingestor.service.spec.ts` |
| Test File (E2E) | `<name>.e2e-spec.ts` | `auth.e2e-spec.ts` |
| Next.js Page | `page.tsx` | `app/sources/page.tsx` |
| Next.js Layout | `layout.tsx` | `app/(dashboard)/layout.tsx` |
| React Component | `<Name>.tsx` (PascalCase) | `SourceTable.tsx` |

## 6. Git Commit Convention

Follow Conventional Commits strictly:

```
<type>(<scope>): <description>
```

- **Types:** `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `perf`, `style`
- **Scopes:** `api`, `web`, `worker`, `database`, `shared`, `ui`, `docs`, `infra`

## 7. Environment Variables

- All uppercase with underscore separation.
- Prefix by app where possible: `API_PORT`, `WORKER_CONCURRENCY_*`.
- Never commit `.env` files to Git. Use `.env.example` as the template.
- Validate all environment variables at application startup — crash fast if required variables are missing.

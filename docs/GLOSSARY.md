# Cipta Glossary — Ubiquitous Language

> All documents, code identifiers, and conversations within the Cipta project **must** use these terms consistently. Ambiguity kills velocity.

---

## Core Domain Terms

| Term | Definition |
|------|-----------|
| **Cipta** | The platform itself. Indonesian for "creation". |
| **Ingestor** | The module responsible for acquiring raw media (scraping, downloading) and extracting intelligence (transcription, LLM analysis). |
| **Factory** | The video production engine. Takes raw media chunks and produces finished, platform-ready video assets using FFmpeg. |
| **Guardian** | The anti-shadowban security layer. Ensures every output video is cryptographically and visually unique to bypass duplicate content detection. |
| **Fleet** | The distribution and account management module. Manages account clusters, scheduling, and automated posting. |
| **Worker** | A standalone Node.js background service that processes jobs from the BullMQ message queue. Completely decoupled from the NestJS API. |
| **Orchestrator** | The NestJS API server. The brain that coordinates all operations via REST/GraphQL APIs and dispatches jobs to the Worker via BullMQ. |
| **Control Tower** | The Next.js dashboard UI where users manage their entire content pipeline. |

## Content Pipeline Terms

| Term | Definition |
|------|-----------|
| **Source** | A URL or uploaded file representing raw, unprocessed input media (e.g., a YouTube video URL, a local MP4 file). |
| **Transcript** | A timestamped text representation of audio content, generated by Whisper API or similar. |
| **Viral Spike** | A segment of a transcript identified by LLM analysis as having high viral potential based on humor, controversy, emotional resonance, or retention hooks. |
| **Chunk** | A discrete segment of video cut from a Source based on Viral Spike timestamps. The atomic unit of the production pipeline. |
| **Variation** | A unique render of a Chunk. The Guardian module ensures each Variation has a unique fingerprint despite being based on the same source Chunk. |
| **Asset** | A finished, ready-to-publish video file. A Variation that has passed all Guardian checks and is stored in Cloud Storage. |
| **B-Roll** | Supplementary footage spliced into a Chunk based on contextual AI analysis of the speech content. |
| **Kinetic Caption** | Animated, burned-in subtitles synchronized to the transcript with word-level timing. |

## Account & Distribution Terms

| Term | Definition |
|------|-----------|
| **Account** | A single social media account connected to the platform (e.g., one TikTok profile). |
| **Cluster** | A logical group of Accounts that share a content strategy, niche, or persona (e.g., "Tech Podcast Clips"). Also referred to as a "Fleet" in user-facing language. |
| **Schedule Slot** | A specific time window calculated by the Predictive Scheduler for optimal posting. Uses non-round times to mimic human behavior. |
| **Pinned Comment** | An auto-generated comment posted immediately after a video goes live, typically containing affiliate links or CTAs. |
| **Engagement Prompt** | Text designed to drive comments and interactions (e.g., "What do you think? Comment below!"). |
| **Cooldown** | A mandatory delay between actions on the same Account to avoid rate-limiting or detection by the platform's anti-bot systems. |

## Technical Infrastructure Terms

| Term | Definition |
|------|-----------|
| **Job** | A unit of work dispatched to the Worker via BullMQ. Each Job has a type (e.g., `ingest`, `render`, `distribute`), payload, priority, and retry policy. |
| **Queue** | A BullMQ queue. Each pipeline stage has its own queue (e.g., `ingestor-queue`, `factory-queue`, `guardian-queue`, `fleet-queue`). |
| **Pipeline** | The full end-to-end flow from Source ingestion to Asset distribution. Composed of sequential stages: Ingest → Factory → Guardian → Fleet. |
| **Fingerprint** | A combination of MD5 hash, visual signature, and metadata profile that uniquely identifies a video file. The Guardian's job is to make each Variation's fingerprint unique. |
| **Metadata Spoofing** | The practice of injecting fake EXIF/encoding metadata into a video to make it appear as though it was recorded on a specific device (e.g., iPhone 15 Pro). |
| **Bitstream Jittering** | Micro-alterations (±1%) to audio/video bitrate to change the file hash without perceptible quality loss. |
| **NVENC / VideoToolbox** | Hardware-accelerated video encoding APIs (NVIDIA / Apple respectively) used by FFmpeg for high-performance rendering. |

## User Segment Terms

| Term | Definition |
|------|-----------|
| **Massive Clipper** | A user persona who clips long-form content (podcasts, streams) into short-form viral clips at scale. |
| **Product Affiliator** | A user persona managing multiple accounts to promote affiliate products with AI-generated scripts and avatars. |
| **AI Influencer** | A user persona managing virtual/synthetic personas with consistent posting schedules driven by AI trend analysis. |

---

## Data Model Terms

| Term | Definition |
|------|-----------|
| **Workspace** | The top-level organizational unit. Groups users, sources, clusters, and billing under one entity. Multi-tenancy boundary. |
| **Project** | A logical container within a Workspace for organizing related Sources, Chunks, and Assets around a theme or campaign. |
| **Render Profile** | A saved configuration of Factory settings (caption style, B-roll rules, aspect ratio, etc.) that can be reused across Chunks. |
| **Distribution Rule** | A configuration that maps a Render Profile to a Cluster with scheduling constraints. Defines what gets posted where and when. |

---

## Convention

When adding new terms to the codebase:
1. Define them here first.
2. Use the exact term in code identifiers (class names, variable names, database columns).
3. Never create synonyms — one concept, one word.
